# 作废必须填原因：空原因被拒绝
$ call POST /api/settlements/2/transit '{"targetStatus":"CANCELLED","version":0,"operator":"财务-小王","requestNo":"REQ-ACC-T-905"}'
{
  "success": false,
  "message": "作废必须填写作废原因（remark）"
}
