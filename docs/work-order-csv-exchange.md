# 作业单 CSV 文件交换规范

作业单主数据的文件交换口径：导出、导入模板、批量导入共用同一套列定义与转义规则。
接口实现见 `WorkOrderExchangeController`，值班处置见 [work-order-csv-runbook.md](work-order-csv-runbook.md)。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/work-orders/export?status=` | 导出作业单 CSV（仅正常单；`status` 可选，取值 CREATED/IN_PROGRESS/COMPLETED/CANCELLED/REVERSED） |
| GET | `/api/work-orders/import-template` | 下载导入模板（仅表头一行） |
| POST | `/api/work-orders/import` | 批量导入，`multipart/form-data`，字段名 `file` |

## 文件格式

- **编码**：UTF-8，文件头带 BOM（U+FEFF）。导出与模板均带 BOM，Excel 双击打开不乱码；导入时自动跳过 BOM。
- **行尾**：导出为 CRLF（`\r\n`）；导入兼容 CRLF 与 LF。
- **表头**：第一行固定为表头，列按**表头名称**匹配，顺序不敏感；未知列忽略。
- **记录**：每行一条作业单；完全为空的行忽略，不计入导入计数。

## 列定义

可交换列（模板列，导入识别）：

| 列名 | 必填 | 约束 | 说明 |
| --- | --- | --- | --- |
| 作业单号 | 是 | ≤40 字符，不得以 `-R` 结尾 | 全库唯一；`-R` 为红冲反向单保留后缀 |
| 农机编码 | 是 | 须已建档且未停用 | 对应 `t_machine.machine_code` |
| 作业类型 | 是 | ≤40 字符 | 如：播种、收割、植保、深松 |
| 地块名称 | 否 | ≤80 字符 | |
| 备注 | 否 | ≤255 字符 | |

导出在可交换列之后追加参考列（导入时忽略）：**状态、轨迹核算面积、人工上报面积**（单位：亩）。

> 面积不允许经 CSV 写入：`trackArea` 轨迹核算面积是权威口径，只能走 `/api/work-orders/{id}/track-area` 登记；`manualArea` 走 `/api/work-orders/{id}/manual-area`。CSV 只交换主数据（单号/农机/类型/地块/备注），状态与面积由系统流程产生。

## 转义规则（RFC 4180 子集）

1. 字段含**逗号、双引号、回车或换行**时，整个字段用双引号包围。
2. 字段内的双引号**双写**（`"` → `""`）。
3. 空字段即空串；CSV 不区分 NULL 与空串，空字段导入按未填写处理。
4. 引号内允许换行（多行字段），解析为同一条记录。
5. 宽松解析：引号未出现在字段起始位置时按普通字符处理，不报错。
6. 导入时字段值做**首尾空白裁剪**后入库（防 Excel 手滑空格）；往返一致以入库值为准。

示例：

```csv
作业单号,农机编码,作业类型,地块名称,备注
WO-2026-001,M-01,播种,东地块,"备注含,逗号"
WO-2026-002,M-01,收割,"西""地块""","备注含""引号"""
WO-2026-003,M-02,植保,南地块,"备注含
换行"
```

## 导入语义

- **逐行独立事务**：一行失败不影响其他行；每行建档 = 请求号登记 + 农机校验 + 落单 + 状态日志，与接口建档同一事务口径。
- **行级请求号**：`{批次号}-{行号}`，批次号形如 `IMP-{32位hex}`，每次导入生成一个；落 `t_request_record` 台账，业务类型 `WORK_ORDER_IMPORT`。
- **幂等**：作业单号已存在的行跳过（`SKIPPED`），不报错、不重复建档。重复导入同一文件，结果全为 `SKIPPED`，库内数据不变。文件内单号重复时，首行建档、后续行跳过。
- **并发口径**：两批同时导入同一文件，唯一约束 `uk_work_order_no` 兜底，每单只建一笔；冲突行该次标记 `FAILED`（提示已存在），重跑一次即转为 `SKIPPED`，最终一致。
- **失败行可定位**：返回逐行结果，`lineNo` 为**数据记录序号**——表头为第 1 行，首条数据为第 2 行，与 Excel/文本编辑器中看到的行号一致；字段含换行的多行记录会占多个物理行，此时以记录序号为准。

导入响应：

```json
{
  "success": true,
  "message": "OK",
  "data": {
    "batchNo": "IMP-9f2c...",
    "totalRows": 5,
    "successCount": 1,
    "skippedCount": 0,
    "failedCount": 4,
    "rows": [
      { "lineNo": 2, "orderNo": "WO-2026-001", "result": "SUCCESS", "message": null },
      { "lineNo": 3, "orderNo": null, "result": "FAILED", "message": "作业单号不能为空" }
    ]
  }
}
```

`result` 取值：`SUCCESS` 新建 / `SKIPPED` 已存在跳过（幂等） / `FAILED` 校验或落库失败（`message` 为原因）。

## 往返一致口径

- 导出文件可直接再导入：参考列被忽略，可交换列逐字识别。
- **导出 → 导入 → 再导出**：可交换列内容一致；因导入只做幂等跳过，两次导出逐字节一致。
- **导入 → 导出**：可交换列与导入源（首尾空白裁剪后）逐字一致。
- 红冲反向单（`reversalFlag=1`，单号 `-R` 结尾）不参与文件交换：导出不包含，导入单号也不允许占用 `-R` 后缀。红冲原单（正常单）照常导出，状态列如实为 `REVERSED`。
- 参考列（状态/面积）由系统流程产生，不纳入往返比对。

一致性由 `WorkOrderExchangeTest#roundTrip_importExportImport_contentStable` 用含逗号/引号/换行的字段守护。
